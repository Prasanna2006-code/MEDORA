# MEDORA

AI-Assisted Hospital Triage and Patient Prioritization System.

## Features

- Patient registration
- Vital and symptom input
- AI-assisted triage
- Critical / Urgent / Non-Urgent classification
- Priority queue
- Patient reassessment
- Triage history
- Unidentified patient handling
- Hospital dashboard

## Tech Stack

- HTML, CSS, JavaScript
- Python
- FastAPI
- SQLite
- Scikit-learn / XGBoost
- Git & GitHub

## Disclaimer

MEDORA is a prototype for AI-assisted triage support and is not a medical diagnosis system.
